# Kalima Level-Up Kit — قالب احتفال الترقية بالدروع العشرة

قالب مستقل لإعادة استخدام تصميم الترقية السينمائي لتطبيق **كلمة** في أي مشروع آخر. لا يغيّر الشيفرة التشغيلية للتطبيق الحالي. جميع الدروع مأخوذة من ملف `dist/assets/kalima-shields.png` الأصلي في مستودع كلمة، ولا توجد دروع بديلة مولّدة.

## المحتويات

- `preview/royal-gold-rank-1000.mp4`: فيديو المرجع بجودة 1080×1920، **60 FPS**، بتوهج ذهبي ونهاية هادئة.
- `assets/kalima-shields.png`: الصورة الأصلية الموحّدة للدروع العشرة (خمسة أعمدة وصفّان).
- `index.html` + `styles.css` + `level-up.js` + `demo.js`: معاينة تفاعلية مستقلة قابلة للدمج.
- `ranks.json`: الدروع والحدود الأصلية لتعلّم المفردات.
- `assets/progress.mp3` و`assets/celebration.mp3`: صوت احتساب النقاط وصوت الاحتفال من التسجيلات التي قدمها مالك المشروع؛ راجع حقوق الاستخدام أدناه.

## طريقة التجربة

شغّل خادمًا محليًا داخل مجلد القالب، مثل:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000` واختر الدرع واضغط **تشغيل احتفال الترقية**. لا يتطلب القالب حسابًا أو Supabase أو React. يستطيع العمل داخل تطبيق Android WebView أو موقع ويب. يعمل الصوت بعد الضغط بسبب قيود المتصفحات؛ **الاهتزاز تلقائي دون زر** في الأجهزة والمتصفحات الداعمة له، ولا يعمل بالطريقة القياسية في Safari على iPhone.

## دمجه في أي تطبيق

يمكنك نسخ القالب كاملًا أو نقل ملفات CSS وJavaScript مع حاوية العرض. لبدء الاحتفال من كودك بعد الضغط على زر أو فعل من المستخدم:

```javascript
const animator = new KalimaLevelUp.LevelUpCelebration('#celebration', {
  ranks: KalimaLevelUp.DEFAULT_RANKS,
  progressSeconds: 4.15,
  sprite: 'assets/kalima-shields.png',
  progressSound: 'assets/progress.mp3',
  celebrationSound: 'assets/celebration.mp3',
  onFinish: (rank) => console.log('Unlocked:', rank.name)
});

// 0 = bronze, 3 = star (1,000 words), 9 = Khaled (10,000 words).
await animator.play(3);
```

في المشاريع المستقبلية تستطيع تغيير عناوين الدروع وحدودها والصوت والمدة، مع الحفاظ على تصميم الدرع. للانتقال إلى مستوى فعلي، اربط استدعاء `play` بشرط تجاوز عتبة الدرع الجديد واحفظ إنجاز المستخدم في قاعدة بياناتك أو التخزين المحلي؛ هذه النسخة **معاينة وقالب** وليست نظام حسابات أو تقدم مستخدم مكتمل.

## تسلسل العرض

1. يبدأ عداد النقاط من صفر ويصل إلى الهدف بينما يرتفع الشريط حتى 100% خلال 4.15 ثوانٍ، مع صوت التقدّم وحده.
2. بعد اكتمال الشريط مباشرة، يظهر **الدرع الحقيقي المطابق للرتبة** في مجموعة الدروع العشرة، ويبدأ صوت الاحتفال.
3. ينبض الدرع مع الترددات المنخفضة (Bass) لثوانٍ، وتتوهج حوافه وتخرج منه أشعة ذهبية؛ ثم يهدأ ويثبت في نهاية العرض.
4. يعتمد الكود `requestAnimationFrame` ويستهدف عرضًا سلسًا حتى 60 إطارًا/ثانية، بحسب أداء الجهاز وشاشة العرض. لا يوجد زر لتمكين/تعطيل الاهتزاز.

## تنبيهات

- التصميم والأصول الخاصة بكلمة محفوظة لسهولة إعادة الاستخدام؛ في أي تطبيق آخر يمكن تغيير العلامة التجارية والكلمات والرتب.
- **حقوق الصوت:** التسجيلات المرفقة تتضمن مؤثرات مقتبسة من لعبة Battlefield وقد تخضع لحقوق EA أو أصحابها. وجودها في هذا القالب لا يمنح ترخيصًا لإعادة التوزيع أو الاستخدام التجاري. استبدلها بمؤثرات لديك حق استخدامها قبل نشر تطبيق مستقل للجمهور.
- ملف فيديو المعاينة موجود للمرجع فقط، ولا يُستخدم بوصفه واجهة تفاعلية.
- لا تنسَ استخدام ملف الدروع **الأصلي** بدل الرسم البرونزي التقريبي الذي استُخدم في معاينات قديمة.
